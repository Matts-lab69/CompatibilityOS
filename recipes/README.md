# Application recipes

I plan declarative, versioned application rules: match predicates, environment settings, high-level DLL overrides, and [versioned `.reg` migrations](../docs/03-registro.md). I review Wine bug reports and protonfixes for evidence and provenance before adopting settings. Candidate DLL families include VC++/MFC, MSXML, GDI+, D3DX, D3DCompiler, .NET and XAudio. I do not redistribute proprietary files or use `umu-launcher`. I have not implemented a schema or recipe yet.
